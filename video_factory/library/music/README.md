# Music library
Drop licensed tracks (mp3/wav/m4a). Put a mood word in the file name or folder so the factory can
choose by mood: `energetic`, `upbeat`, `inspiring`, `uplifting`, `dramatic`, `cinematic`, `calm`,
`lofi`, `corporate`, `tech` … e.g. `inspiring/rise_up_120bpm.mp3`. Music is auto-looped, faded and
side-chain ducked under the voice.
