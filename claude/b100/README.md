- **מניעת כפילויות תקינה.**

- **מה נשלח מגובב ב-CAPI (לפי מה שנבנה ב-ב9/ב25 ונרשם בשליחה הידנית של 12.11):**

  - **לא ידוע שנשלחים:** fn, ln, external_id, client_ip_address. ה-webhook של דף התשלום לא שומר headers, ולכן IP כנראה לא נשלח. כדי לוודא צריך לפתוח את מודולי ה-CAPI ב-7827404 בממשק (רשימה בסעיף 3).
- **פיקסל הדפדפן:**

  - **בדף התודה:** ה-init בלי ud. ה-Purchase מהדפדפן נושא רק עוגיות, IP ו-UA, וההתאמה של em/ph מגיעה רק מה-CAPI.
