# ב85 - a5v6 (בן 12.11: חוזרים לגרסה הקודמת)

`claude/b68/s15/build_v6.py` בונה את a5v6 מתוך הבנייה של a5v4 (אותה פונקציה, v=a5v6), ומוסיף רק את שכבת הכפתורים. a5v4 ו-a5v5 לא משתנים.

## כל ההבדלים מול a5v4
1. data-variant=a5v6 (מדידה ומעבר לסליקה עם v=a5v6). noindex, לא ב-go.html ולא בניסוי.
2. כל 10 כפתורי ההצטרפות (hero_main, cta1, know, cta2, peek, offer, cta3, final, sticky, stories) כמו ב-pr2:
   - רקע #18845A (בריחוף #136B49), טקסט לבן מודגש 800, 18px, פינות 14px, אותו צל. בלי הזהב, הברק (shine) והפעימה (pulse1) של a5v4.
   - רטט + ring כמו ב-pr2: אותם keyframes (shk 0.72s, ring 0.9s), כל ~4 שניות, הכפתור הבולט במסך (90%+) והכפתור הצמוד כשהוא מוצג.
     כבוי בהפחתת תנועה וב-?shake=0, ולא בזמן שסרטוני ההמלצות פתוחים.
   - "תשלום מאובטח" עם המנעול יצא מתוך הכפתור, ומתחת לכל כפתור בדף יש "🔒 תשלום מאובטח" (8 כפתורים + כפתור ההמלצות = 9).
     בכפתור הצמוד אין שורה כזו, כמו ב-pr2.
3. אין שום הבדל אחר: אותו סדר וקופי, אותן תמונות וסרטונים, אותם data-cta וקישורים לסליקה, אותן תגיות section_view.

## אזור הקורס וההצעה
כבר בסדר של בן ב-a5v4 ונשאר כך: "מה יש בפנים" → "👇 תגלול ותראה בעצמך..." → (סיור ע21 כשיגיע) → ההצצה לשיעור ע20 →
"וזה עוד לפני שדיברנו על כל הבונוסים שמחכים לך…" → 5 הבונוסים עם התכנים והשווי → סיכום ההצעה (שווי כולל 2,411, "מחיר כולל הבונוסים 2,411" מחוק, 297, כפתור).
