## מדידה
- variant `a5v7`, ו-noindex כמו ב-a5v6.
- קישורי הסליקה זהים, עם `utm_content=lp_a5v7&v=a5v7`.
- **מספרי הסקשנים:** `data-sec` ממוספר מחדש 1 עד 14 לפי הסדר החדש. אירוע `section` ופס ההתקדמות מניחים מספרים עולים.
- **section_view:** לכל שלב (`data-stage`) כמו ב-a5v6, כולל guarantee.
- **מזהי כפתורים:** hero_main, know, cta2, peek, offer, guar, cta1, final, sticky, stories.
