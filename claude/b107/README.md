## 2. מקורות חינם
- source() בדשבורד:
  - utm_source=whatsapp (או wa) → "וואטסאפ (קבוצות)"
  - utm_source=facebook (או fb) עם utm_medium=page או page_post → "דף הפייסבוק"
  - שני הכללים לפני "מייל", "אינסטגרם אורגני" ו"פייסבוק אורגני".
- טבלת "מקורות חינם": אינסטגרם אורגני, וואטסאפ, דף הפייסבוק, פייסבוק אורגני, מייל, ManyChat, Meta (fbclid), ישיר. לכל מקור: אתמול, 7 ימים, 14 ימים, הגיעו לדף התשלום, השאירו פרטים.
- לבן: כדי שהמקורות ייספרו, הקישורים בקבוצות הוואטסאפ צריכים לכלול `?utm_source=whatsapp&utm_medium=group`, והקישורים בפוסטים בדף הפייסבוק `?utm_source=facebook&utm_medium=page_post`. אפשר להוסיף גם `&utm_campaign=<שם>`.
- בפריסה גם campaign.html ישתנה: build_campaign.py מעתיק את source() מהדשבורד, ולכן הדף "הקמפיין" יכיר את שני המקורות החדשים.
