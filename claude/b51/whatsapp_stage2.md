# ב51 שלב 2 - וואטסאפ אוטומטי (תכנון, בלי שליחה)

השלב הזה מחכה לבן. צריך WhatsApp Business API על מספר עסקי, ועדיף מספר ייעודי, כי חיבור ל-API מנתק את המספר מאפליקציית הוואטסאפ הרגילה. החיבור עובר דרך ManyChat, שכבר עובד באינסטגרם. את החיבור למטא בן יוצר, ומטא צריכה לאשר את התבנית.

## התבנית (Utility או Marketing, לפי מה שמטא תאשר)
- **בלי ניסיון תשלום** (`recovery_open`): היי {{1}}, כאן מהצוות של בן נחום. ראינו שהתחלת להצטרף ל"לנצח את האוטומט" ועצרת לפני התשלום. איך נוח לך להמשיך?
- **למי שניסה לשלם ונכשל** (`recovery_failed`): היי {{1}}, כאן מהצוות של בן נחום. ראינו שניסית להצטרף ל"לנצח את האוטומט" והתשלום לא עבר. לא ירד ממך כסף. איך נוח לך להמשיך?
- **3 כפתורי תשובה מהירה:** יש לי שאלה / רוצה להמשיך לרכישה / לא כרגע

## מה קורה בכל כפתור (Flow ב-ManyChat)
- **יש לי שאלה:**
  - הודעה: "בשמחה. כתוב כאן את השאלה, ומישהו מהצוות יחזור אליך בהקדם."
  - השיחה מועברת לתיבה האנושית, ויהב מקבל התראה מיידית.
  - מי שעונה מציג את עצמו בשמו, מהצוות של בן.
- **רוצה להמשיך לרכישה:**
  - הודעה: "מעולה. הנה הקישור, זה לוקח דקה: {קישור}. אם התשלום באפל פיי או בגוגל פיי לא עובר, בהקלדת פרטי הכרטיס זה עובד."
  - הקישור: `checkout.html?v={variant}&utm_source=whatsapp&utm_medium=recovery&utm_content=wa_auto`
- **לא כרגע:**
  - הודעה: "תודה שעדכנת, זה בסדר גמור. אם תרצה לחזור, הקישור כאן: {קישור}. ואם בא לך לשתף, מה עצר אותך?"
  - אפשרויות תשובה: המחיר / לא בטוח שזה מתאים לי / אין לי זמן עכשיו / משהו טכני.
  - בכפתור הזה מסמנים `stop=wa_not_now`, וזה עוצר גם את המיילים.

## ההפעלה מ-Make (תוספת לתרחיש v2, מסלול "וואטסאפ אוטומטי")
- **תנאים:** consent=1, לא רכש, stop ריק, אין wa_at, השעה בין 08:30 ל-22:00, ועברו שעה מהשארת הפרטים (15 דקות למי שנכשל בתשלום).
- **מה קורה:** קריאה ל-ManyChat API (`/fb/sending/sendFlow` או set custom field + trigger, לפי מה ש-ManyChat מאפשר ל-WhatsApp) עם הטלפון והשם, ואז שמירה של `wa_at=now` ב-210989.
- **חזרה מ-ManyChat:** ManyChat מחזיר את הבחירה ל-hook של המעקב (7798267) עם `ev=wa_choice`, `name=question/buy/not_now/<סיבה>` וה-sid של הליד.
  - הבחירה נספרת בדשבורד במסך 04, באזור "החזרת נוטשים".
  - "לא כרגע" מעדכן `stop` ב-210989.
- **מה צריך מבן:** מספר, חיבור WhatsApp Business ב-ManyChat, אישור התבנית במטא ומפתח API של ManyChat. את המפתח לא מעתיקים למסמכים, ושומרים אותו בחיבור ב-Make.
